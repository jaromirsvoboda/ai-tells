# AI tells

A dated, sourced catalogue of the signs that give AI-generated content away — text, images, video, audio, design and
code — sorted by when each sign appeared and whether today's models still show it; plus a quiz: can you tell
human-made from AI-made?

- Catalogue: `index.html`
- Quiz: `quiz/`

Compiled by Jaromír Svoboda with AI research assistants (Claude, Codex, Gemini, Qwen); every claim links to the source
it was checked against. Image and text credits: `quiz/CREDITS.md`.
